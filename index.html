一个插件，三种干净

截图和隐藏是两套独立能力，互不干扰。想临时处理一张图，就截图；想长期清掉某个站点的干扰，就隐藏。

截图 · 先消除，再截取

鼠标悬停就近高亮，滚轮把范围扩到整块容器，点击后内容真实退出布局、下方自动上移。截完页面 100% 复原。

  • 消除 / 选元素 / 圈选三种模式
  • 截后画箭头、打码、裁切
  • 保存加复制，历史可定位文件

隐藏 · 标记一次，长期生效

按站授权后，点一下元素就立刻从页面消失。保存成规则后，以后打开这个网站它都自动隐藏。

  • 连续多选，点错随时撤销
  • 规则显示真实匹配状态
  • 支持 Shadow DOM，可临时禁用

AI · 少点很多下

点一个元素找出所有同类的；或让启发式扫描把疑似广告和悬浮层框出来。都不联网。

  • 找同类：按结构匹配同构元素
  • 智能扫描：按特征打分找干扰
  • 可选：用你自己的 Key 做语义分析

三步就上手

不用注册，不用配置。装好之后，你想处理的那个页面就是入口。

01

点图标

在想处理的页面点 Capx 图标，或者按 Alt + Shift + X，控制条就出现在页面顶部。

02

点内容

截图模式下点一下消除，隐藏模式下点一下标记。可以连续点多个，错了随时撤销。

03

截图或保存

要图片就截取导出；要永久隐藏就点保存。截图退出后页面自动复原。

几个常见问题

截图之后，页面会变吗？

不会。消除只是临时的，导出截图后页面会 100% 还原，连元素原本的 style 属性都会恢复原样。按 Esc 也能随时退出还原。

隐藏规则会在什么时候生效？

你授权过的站点，每次页面加载时隐藏脚本都会自动运行并应用规则。不需要再点 Capx 图标。网站改版导致规则失效时，弹窗里会显示匹配数为 0，重新拾取一次即可。

安装时会申请所有网站权限吗？

不会。安装时只有截图所需的 activeTab 等基础权限。隐藏功能要用到「按站授权」：你点「启用本站」并同意后，才拿到那一个站点的权限。AI 分析也只在保存 API 配置时单独请求对应域名。

能把某个元素恢复回来吗？

能。在弹窗的「本站规则」里可以临时禁用单条规则，或者直接删除。删除并刷新后，元素就恢复了。
