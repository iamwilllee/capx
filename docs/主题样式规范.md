# Capx 主题样式规范（跨项目移植版）

> 一份可直接复制的深色/浅色双主题设计系统。纯 CSS，不依赖任何框架或组件库。
> 来源：Capx Chrome 扩展。设计原则：**中性表面家族 + 单一强调色只做点缀 + 圆角四档 + 阴影两档 + 统一动效**。

## 1. 快速开始

三步接入：

**① 复制 tokens.css**（见第 2 节）到你的项目，比如 `styles/tokens.css`。

**② 全局引入**：
```css
@import './styles/tokens.css';
```

**③ 在根节点上标记主题**（`auto` / `light` / `dark`）：
```js
function applyTheme(theme) {
  const resolved = theme === 'auto'
    ? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light')
    : theme;
  document.documentElement.setAttribute('data-theme', resolved); // 注意属性名
}
applyTheme('auto');
matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => applyTheme('auto'));
```

之后所有组件样式都用 `var(--capx-*)`，切换根节点属性即可整体换肤。

> **换色/换品牌**：只需改 tokens 里 `--capx-accent` 系列（强调色）和表面/文字色，全站自动跟随。

## 3. 主题切换机制

### 3.1 三态主题

| 值 | 行为 |
|---|---|
| `auto` | 跟随系统 `prefers-color-scheme`，并实时监听变化 |
| `light` | 强制浅色 |
| `dark` | 强制深色 |

### 3.2 关键点：属性名要一致

JS 写入的属性名，必须和 CSS 选择器里的完全一致。本项目用 **`data-capx-theme`**：

```js
// JS 写
document.documentElement.setAttribute('data-capx-theme', 'light');
```
```css
/* CSS 读 */
:root[data-capx-theme='light'] { ... }
```

移植到你的项目时，建议改成通用名 `data-theme`，两处同步改即可：
```js
document.documentElement.setAttribute('data-theme', resolved);
```
```css
:root[data-theme='light'] { ... }
```

### 3.3 完整 React Hook 参考

```tsx
type Theme = 'auto' | 'light' | 'dark';

function useTheme(theme: Theme) {
  useEffect(() => {
    const mq = window.matchMedia('(prefers-color-scheme: dark)');
    const apply = () => {
      const resolved = theme === 'auto'
        ? (mq.matches ? 'dark' : 'light')
        : theme;
      document.documentElement.setAttribute('data-theme', resolved);
    };
    apply();
    if (theme === 'auto') {
      mq.addEventListener('change', apply);
      return () => mq.removeEventListener('change', apply);
    }
  }, [theme]);
}
```

> **多页面/多上下文注意**：如果是浏览器扩展，注入到宿主页面时，宿主页面的 `documentElement` 不能随便加属性。本项目的做法是内容脚本在注入时设置 `data-capx-theme`、退出时清除（只影响 `--capx-*` 前缀变量，不污染宿主样式）。普通 Web 项目无此顾虑。

以下样式**全部只引用 tokens**，换主题即整体换肤。可直接复制改造。

### 4.1 主按钮（淡染 + 描边，不满色）

```css

  width: 100%; height: 40px; padding: 0 12px;
  border: 1px solid var(--capx-accent-line);
  border-radius: var(--capx-r-md);

  color: var(--capx-accent);

  cursor: pointer;
  transition: background var(--capx-dur) var(--capx-ease),
```

## 5. 配色设计逻辑

理解这几点，才能改得不出乱子：

1. **表面三层递进**：`bg`（最底）→ `surface`（卡片）→ `surface-2`（控件槽）。浅色主题下卡片反而更亮（白），控件槽更暗（灰），形成"内凹"层次。
2. **强调色只做点缀**：青色只出现在 logo、主按钮、色板、选中描边、链接 hover。**绝不铺满大背景**。全站满色青会显得用力过猛、失去重点。
3. **文字三级**：主文字 / 次要（未选中项）/ 最弱（分区标题、提示）。分区标题用小字号+大字距+大写，弱化但不消失。
4. **状态靠明度而非颜色**：开关选中态在深色主题下是"亮底+深 thumb"，浅色主题下自动反转成"深底+浅 thumb"——因为用的是 `var(--capx-text)` 和 `var(--capx-bg)`，主题切换自动适应。
5. **淡染用 color-mix 不用固定 rgba**：这样强调色换色时，淡染背景自动跟随。

## 6. 踩坑记录

| 坑 | 原因 | 解法 |
|---|---|---|
| **Switch thumb 贴顶"歪掉"** | flex 容器默认 `align-items: stretch`，thumb 固定高度时被顶到起点 | `.sw` 加 `align-items: center` |
| **状态选择器不生效** | Base UI 用 `data-checked` / `data-pressed`；Radix 用 `data-state='checked'` / `data-state='on'` | 按所用组件库的选择器写 CSS |
| **Chrome 扩展弹窗外围圆角改不了** | popup 内容只是窗口内的 iframe，宿主窗口形状由 Chromium 控制 | 放弃给 `body` 加 `border-radius`（无效）；只给内部卡片加圆角。要真圆角只能改用独立窗口或页内模态框 |
| **content script 的 IndexedDB 读不到** | 它属于宿主页面 origin，与扩展 origin 不共享 | 经 background 消息中转读写 |
| **开关被压成竖条（16×55）** | flex 子项未固定尺寸时被挤压 | `display:inline-flex; flex-shrink:0` + 显式宽高 |
| **弹窗出现滚动条** | Chrome popup 默认最大高约 600px，内容超高 | 压缩纵向间距；用细滚动条样式兜底 |

## 7. 移植清单

复制到新项目时，逐项确认：

- [ ] 复制 `tokens.css`，`@import` 到全局样式
- [ ] 确认 JS 写入的属性名与 CSS 选择器一致（`data-theme` 或 `data-capx-theme`）
- [ ] 实现三态切换 Hook（`auto` 要监听 `prefers-color-scheme`）
- [ ] 全站样式改用 `var(--capx-*)`，**不再硬编码颜色/圆角/阴影**
- [ ] 组件库状态选择器对齐（`data-checked` / `data-pressed`）
- [ ] Switch 容器加 `align-items: center`
- [ ] 如需换品牌色，只改 `--capx-accent` 系列 + 表面/文字色
- [ ] 浏览器兼容：`color-mix()` 需 Chrome 111+ / Safari 16.2+；不支持环境可用固定 `rgba()` 替代 `accent-soft`
