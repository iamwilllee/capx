# Capx —— 截图 + 永久隐藏不想看的元素

一个 Chrome MV3 扩展，两个独立功能：

1. **截图**：在页面上**临时消除**不想要的内容（下方自动重排填补），立刻**圈选截图**，导出后页面**自动 100% 复原**（`activeTab` 按需注入，勿需网站权限）。
2. **隐藏元素**：按站授权后，**永久隐藏**你标记过的元素——以后打开该站点页面就自动生效，与截图完全独立（见下文「隐藏元素」）。

> 解决的核心痛点：以前想去掉页面中间某块内容，得先用 DevTools 删节点、再换截图工具截图、最后手动撤销。Capx 把这三步合成一个连贯动作，且保证页面无痕恢复。

---

## 安装（开发者模式加载）

项目用 **WXT** 构建，加载的是构建产物而不是源码目录：

```bash
pnpm install       # 首次安装依赖
pnpm dev           # 开发：自动起浏览器 + 热更新（产物 .output/chrome-mv3-dev）
pnpm build         # 生产构建 → .output/chrome-mv3
pnpm zip           # 打包上架用的 zip
```

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择 `.output/chrome-mv3/`
4. 工具栏出现 Capx 图标即安装成功（可点拼图图标把它固定出来）

> `ext/` 是接入 WXT 之前的旧版直装目录，已停止维护，仅作对照保留；新版一律从 `.output/chrome-mv3/` 加载。

## 使用

1. 点工具栏 Capx 图标（或快捷键 `Alt + Shift + X`）→ 页面顶部出现控制条
2. 顶部有三个模式，**随时切换**（也可按数字键 `1` / `2` / `3`）：

   | 模式 | 快捷键 | 用途 |
   |---|---|---|
   | **消除** | `1` | 点击内容即移除，下方自动上移填补 |
   | **选元素** | `2` | 悬停高亮元素，**点击（或回车）即截取该元素** |
   | **圈选** | `3` | 拖拽框选任意区域截图 |

3. **消除模式**（先去掉不想要的内容）
   - 鼠标移到哪就高亮最近的元素，光标变成青色准星框提示「可点击」
   - 点击即消除；**滚轮**把高亮范围扩到外层容器（调好后在容器内移动不会乱跳）
   - 支持跨 Shadow DOM 边界；点错按 `Ctrl/Cmd + Z` 或点「撤销」
4. **选元素模式**（截某一块）
   - 悬停要截的元素 → 点击它（或按回车 / 点「截取此元素」）→ 直接截下这块
   - 想截整张卡片？先滚轮上滚把高亮提到卡片层，再点击
5. **圈选模式**（截任意区域）
   - 拖拽框选，实时显示尺寸，松开即截图
6. 截图自动**保存 + 复制到剪贴板**，随后页面**自动恢复原样**
7. 任何时刻按 `Esc` 退出并恢复页面

> 首次使用会弹出三步引导，点「知道了，开始」即可。

> 说明：消除模式下「点谁消谁」——点到按钮等任何元素都会把它消除（不会触发按钮原本功能），这就是它的用途。

## 隐藏元素（独立功能，与截图无关）

弹窗顶部有两个入口：**截图** 和 **隐藏元素**。后者用于「刷某个站点时把不喜欢的东西永久去掉」，和截图的一次性消除是完全独立的两套逻辑：截图是临时的、退出即复原；隐藏是常驻的、按站点长期生效。

### 用法

1. 打开弹窗 → 切到 **隐藏元素**
2. 点 **启用本站自动隐藏** → Chrome 弹出授权框 → 同意（只授权当前站点，不是所有网站）
3. 点 **拾取元素隐藏** → 页面顶部出现橙色提示条，光标变准星
4. 悬停高亮，滚轮可把选择提升到外层容器；**点击元素会立刻从页面消失**（所见即所得），可连续点多个
5. 顶部实时显示「已隐藏 N 项 / M 个元素」；点错了点 **「撤销」**（或 `Ctrl+Z`）恢复最后一项，点 **「明细」** 可逐项恢复
6. 选完点 **「保存 N 项」** → 一次性存为永久规则；点「退出」则本次隐藏全部还原（不保存）

之后打开该站点的任何页面，这些元素在页面加载时就会自动隐藏；JS 异步渲染出来的元素也会被补隐藏。按 Esc 可随时退出拾取模式，不影响已保存的规则。

### 为什么刷新后要能自动生效

授权站点的隐藏脚本用 `chrome.scripting.registerContentScripts` **动态注册**（不是每次导航手动注入）。浏览器会在该站点的每次页面加载（含刷新）时自动注入脚本，脚本启动时读取规则并静默隐藏——这样不受事件竞态影响。撤销授权时自动注销。

### 规则匹配诊断

动态页面（如 X/Twitter）的 class 名刷新后会变，可能导致选择器失效。为此：

- 生成选择器时**剔除构建工具动态 class**（`css-xxx`、`r-xxx`、`sc-xxx` 等），优先用稳定 id / 语义 class / 结构路径
- 每条规则同时记录**文本锚点**：万一选择器匹配 0 个元素，自动按文本找回（所见即所得）
- 弹窗「本站规则」每条都显示实测状态：当前页匹配几个、还有几个没隐藏、是否靠文本匹配兜底
- 如果显示「匹配 0 个 · 选择器已失效」，删掉旧规则重新拾取即可
- 点「重新应用」可让当前页面立刻重新跑一遍规则

### AI 智能消除（v3.2）

弹窗「隐藏元素」里新增 **AI 智能消除**，三种方式：

| 方式 | 是否联网 | 做法 |
|---|---|---|
| 找同类 | 否 | 点一个元素当样本，按结构签名找出所有同构元素，勾选后一次隐藏 |
| 智能扫描 | 否 | 按定位方式 / 层级 / 类名 / 文案打分，框出疑似广告、推荐位、悬浮层 |
| AI 分析 | 是（可选） | 用你自己填的 API Key 调用大模型，按页面语义挑出干扰内容 |

- 所有结果都**先高亮预览**（紫色虚线框），勾选确认后才加入本次隐藏
- 嵌套重复会被自动去重，只保留最外层，避免一个广告生成三条规则
- 「找同类 / 智能扫描」纯本机计算；「AI 分析」默认关闭，Key 只存 `chrome.storage.local`

> AI 分析会把**当前页面元素的结构信息**（标签、class、可见文字片段、位置尺寸）直接发给你选择的服务商，不经过任何中间服务器。截图、浏览历史、Cookie、隐藏规则都不会发送。详见 [`privacy.html`](privacy.html)。

### 规则管理

- **本站规则**：查看选择器、匹配数、作用域（普通 DOM / Shadow DOM）；每条可临时禁用（不删规则）、删除；一键清空本站
- **所有站点**：展开查看全部站点的规则，可跨站删除
- 规则只存本机 `chrome.storage.local`，不上传

### 权限说明

- 安装时**不申请任何网站权限**（截图仍只用 `activeTab`）
- 用 `optional_host_permissions` + 按站授权：只有你点「启用本站」并同意后，该站点的页面加载才会注入隐藏脚本
- 想停用：在弹窗点「停用本站」，或到 `chrome://extensions` 的站点访问设置里撤销

## 历史记录

弹窗下方展示**最近 20 张**截图的缩略图：
- 点缩略图 → 看大图
- 悬停缩略图 → 左上角 📋 **复制原图**到剪贴板（存的是完整原图，不是糊缩略图）、右上角 📂 在文件夹里定位
- 一键清空（同时清掉缓存的原图）

缩略图存 `chrome.storage.local`（省空间），原图存扩展 IndexedDB（经 background 中转，因 content script 的 IndexedDB 属于宿主页面、与扩展不共享）。历史仅存本机，不上传。

## 截后标注编辑器（v1.0 / v1.1）

在弹窗里开启「截图后先编辑」，每次截图后会弹出编辑画布：
- **工具**：箭头 / 矩形 / 文字 / 画笔 / **马赛克** / **裁切**
- **样式**：6 种颜色 + 4 档线宽（箭头/矩形/文字/画笔）
- **撤销 / 重做**：`Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`（或 `Ctrl+Y`）
- **文字**：选文字工具后点画布任意处输入，回车提交
- **马赛克（v1.1）**：拖拽涂抹即打码，块大小随线宽变化，可撤销
- **裁切（v1.1）**：拖出选框 → 点「应用裁切 ✓」（或回车）裁掉外围；「重设」重画。裁切会先压平已有标注再裁剪，坐标不漂移
- **完成 ✓**：把标注烘焙进原图（保持原始分辨率）再导出；**取消**：放弃本张不保存
- `Esc` 取消编辑

## 设置（点插件图标弹出的弹窗里）

| 设置 | 说明 |
|---|---|
| 导出后自动恢复 | 默认开。关闭则截完保留消除状态，按 `Esc` 手动恢复 |
| 截图后先编辑 | 默认关。开启则截完先进标注编辑器，确认后才导出 |
| 导出格式 | PNG / JPG |
| 截图后 | 保存+复制 / 仅复制（复制失败会自动改下载） |
| 保存子文件夹 | 默认 `Capx`，即保存到 `下载/Capx/`。可改成任意相对子路径（如 `Screenshots/Capx`），留空 = 下载根目录。输入非法（`..`、Windows 保留名等）会标红且不保存 |
| 高亮描边颜色 | 青 / 紫 / 绿 / 橙 |
| 界面主题 | 跟随系统（默认）/ 浅色 / 深色，弹窗与页面内覆盖层同步切换 |

> **保存位置 & 找不到截图？** Chrome MV3 的 downloads API 只能写「下载目录内部」，无法写 `~/Documents` 等任意绝对路径（API 直接拒绝），故采用「下载目录内自定义子文件夹」。弹窗「最近截图」区会显示 `截图保存在：下载 / Capx /`，每张缩略图悬停后有 📂 按钮，点它用 `chrome.downloads.show()` 在访达/资源管理器里直接定位并选中文件。写入任意目录需要 File System Access API + 持久句柄（每次重启要重新授权），复杂度高、体验反而差，故不采用。

## 技术要点

- **真移除而非打码**：用 `display:none !important` 让元素退出布局，下方内容真实上移重排；记录每个元素原本的 `display` 值与 `style` 属性，导出后逐一还原，连空的 `style=""` 属性也会清掉，做到完全无痕。
- **链式层级选择（v0.2）**：命中测试用 `elementFromPoint` + 递归下钻 `shadowRoot` 得到最深元素，再沿 `parentElement / getRootNode().host` 构建祖先链。滚轮在链上前后移动，天然穿透 open Shadow DOM 边界。
- **SPA 重渲染防护（v0.2）**：每个被消除元素挂一个 `MutationObserver` 监视其 `style` 属性；页面框架改回去时在下一帧重新压制。节点被整体替换（克隆/重渲染）时自动清理失效记录，恢复不报错；同一元素被反复重置超过 50 次则放弃并提示，避免与页面无限拉锯。
- **隐藏元素是独立功能**：与截图完全解耦——截图是 activeTab 按需注入的一次性操作，隐藏是用户按站授权后由 `webNavigation.onCommitted` 在页面加载时自动注入的常驻脚本。两者有各自的内容脚本（`capx.js` / `hide.js`）、各自的覆盖层样式、各自的入口。共享的只有设计令牌与规则存储。
- **最小权限（v0.2）**：仅用 `activeTab`，不再声明“读取所有网站数据”。点击图标时才按需注入，安装时权限提示更克制、商店审核更友好。
- **整元素截取 & 历史 & 引导（v0.3）**：复用链式选择，回车 / 按钮直接截当前高亮元素；每次成功截图生成 320px 内 JPEG 缩略图存入 `chrome.storage.local`（封顶 20 条，最近在前）；首次启动弹三步引导并记 `capxOnboarded` 标记，不再重复。
- **截后标注编辑器（v1.0）**：截图后可选进入全屏画布，支持箭头/矩形/文字/画笔 + 颜色/线宽 + 撤销重做。标注坐标按显示尺寸记录，导出时按 `1/scale` 映射回**原始分辨率**烘焙，保证清晰度不损。编辑器接管期间暂停页面级消除快捷键，避免误触。
- **马赛克 & 裁切（v1.1）**：马赛克用低分辨率取样图近邻放大铺到笔触上（跨帧/导出一致）；裁切采用「先压平当前标注→再裁剪→替换底图」策略，避免裁切后标注坐标系漂移。
- **三模式架构（v1.3）**：工具栏改为「消除 / 选元素 / 圈选」三个并列模式（数字键 1/2/3 切换），消除与截取职责分离——不再出现「想截元素却先把元素删掉」的歧义。悬停高亮与滚轮调层级在消除/选元素两个模式共用。
- **WXT 工程化（v1.4）**：从「手写 ext 目录 + 手改 manifest」迁到 WXT。入口即文件（`entrypoints/*`），manifest 由 `wxt.config.ts` 生成；内容脚本用 `registration: 'runtime'`，**依然不写 manifest.content_scripts、不申请 host_permissions**，注入链路保持 `activeTab` 按需注入（`src/lib/capture.ts` 先 ping 再 `executeScript` + `insertCSS`）。`pnpm dev` 有热更新，`pnpm zip` 直接出上架包。
- **组件库（v1.5）**：弹窗用 React + **Base UI 无样式原语**（`Switch` / `ToggleGroup`+`Toggle` / `Dialog`）+ `lucide-react` 图标——只买"行为"（键盘、焦点、无障碍、受控状态），样式全部自己写。没有引入 Mantine/Ant 这类整套库，避免为一个 340px 弹窗背几十 KB 主题与样式重置。可复用控件集中在 `src/popup/ui.tsx`（`Row` / `Toggle` / `Segmented` / `Swatches`）。注意 Base UI 的状态属性是 `data-checked` / `data-pressed`（Radix 是 `data-state`），CSS 选择器按它写。
- **弹窗外观修正（v1.6）**：修复 Base UI `Switch` 的 thumb 因 flex 容器缺 `align-items:center` 而贴顶「歪掉」的问题，现在上下间距一致、垂直居中。压缩弹窗纵向间距（无历史时高度 670→581px，尽量避开 Chrome popup 约 600px 的滚动条阈值）；有历史缩略图超高时，用细滚动条（`scrollbar-width:thin` + 6px 自定义 thumb）替代默认粗灰条。
- **弹窗圆角的边界**：Chrome 扩展 popup 的**外围窗口形状完全由 Chromium 控制**，网页 CSS 无法给它加圆角（popup 内容只是窗口内的 iframe，宿主窗口不可控）——这是 Chromium 开发者的明确答复，业界公认无解。故不在 `body` 上做无效的 `border-radius`；内部卡片（设置区/历史区）保留圆角。若确实需要自定义窗口外形，只能放弃 popup、改用「打开新窗口」或「注入页面内模态框」两种形态。
- **主题系统（v1.6）**：新增 `theme` 设置（auto / light / dark），弹窗监听 `prefers-color-scheme` 实现跟随系统；`tokens.css` 用 `:root[data-capx-theme='light']` 定义整套浅色变量（表面/文字/描边/阴影/强调），与深色共用一份令牌。内容脚本注入时把解析后的主题写到宿主 `<html data-capx-theme>`，退出时清除，不污染宿主页面；页面内覆盖层与弹窗同步明暗。
- **历史快捷复制（v1.6）**：每张历史缩略图悬停后左上角出现 📋 按钮，点它把**完整原图**写入剪贴板（可直接粘贴到微信/文档）。原图存扩展 IndexedDB、缩略图存 `chrome.storage.local`；因 content script 的 IndexedDB 属于宿主页面 origin、与扩展不共享，截图时由 content 经 `capx:store-image` 消息发给 background 写入，弹窗复制时经 `capx:get-image` 读回。新增 `clipboardWrite` 权限。清空历史会同步清空原图缓存，避免膨胀。
- **保存定位（v1.6）**：`chrome.downloads.download` 回调的 `downloadId` 经消息链回传并存进历史项；缩略图悬停显示 📂 按钮，点它调用 `chrome.downloads.show(id)` 在访达/资源管理器中定位文件，解决「下载了却找不到」。
- **配色收敛（v1.6）**：弹窗主按钮从满色青+发光改为「淡青底 + 青字 + 青边」去发光；开关选中态改中性亮灰白，青色只保留在 logo、主按钮与色板；分区标题/快捷提示/次要文字提亮，卡片底色提亮并加强边框分组。修复 Base UI `Switch` 在 flex 容器里被压成 16px 竖条的问题（补 `display:inline-flex; flex-shrink:0`）。
- **保存子文件夹（v1.6）**：截图不再散落下载根目录，默认写入 `下载/Capx/`。新增 `saveDir` 设置支持任意相对子路径（多级、留空=根目录），弹窗侧严格校验（`..`、Windows 保留名、非法字符、长度），内容脚本侧再做一层防御性清洗兜底；下载失败通过回调回传并 toast 提示。修掉了「插件已激活时再次点图标会重复挂载监听，一次点击触发两次截取」的老 bug。
- **设计令牌收敛（v1.5）**：`src/styles/tokens.css` 成为唯一色板来源，**弹窗与页面覆盖层共用**。覆盖层原本自成一套青调灰（`#132a30 / #1d4750`），现在全部改走 `--capx-surface / --capx-line / --capx-text*`，圆角统一四档（`3 / 6 / 10 / 14`，3 仅用于选框/手柄），阴影两档；青色从"6 处满色"收回到只做强调——高亮标签与尺寸徽章由满色胶囊改为**深底 + 青字**，模式切换的激活态改为**淡染 + 描边**，把满色留给唯一的主行动按钮。悬停标签的提示文字也随模式变化（消除模式「点击消除」/ 选元素模式「点击截取」）。
- **交互手感（v1.2）**：悬停可消除元素时切换为自定义准星光标（可发现性）；滚轮提升层级后「锁定」该容器，鼠标在其内部移动保持高亮不乱跳，移出才解除。
- **裁剪换算**：`captureVisibleTab` 返回设备像素图，按 `devicePixelRatio` 把 CSS 选区换算成像素坐标裁剪。
- **零联网、纯本地**：不收集任何数据。

## 已知边界

- **跨域 iframe 内的元素无法消除**（同源策略限制），但该区域仍可被框选截图。
- **closed shadow root** 无法穿透（浏览器不暴露其内部），open shadow root 已支持。
- 仅截取**当前可见视口**内的区域（滚动长截图属于 P1 后续）。
- `captureVisibleTab` 需要页面处于活动标签页；浏览器内置页（`chrome://`、扩展页等）不允许注入。
- `activeTab` 授权会随导航失效：若提示无法注入/截取，重新点一次 Capx 图标即可。

### 隐私政策托管（GitHub Pages）

隐私政策需要公开 HTTPS 地址，仓库已内置 `privacy.html`，推荐用 GitHub Pages 免费托管：

1. 把代码推到 `https://github.com/iamwilllee/capx`
2. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `main`、目录选 `/ (root)` → Save
3. 等 1–2 分钟，访问 `https://iamwilllee.github.io/capx/privacy.html` 确认可打开
4. 把该网址填进 Chrome 网上应用店后台的「隐私政策网址」

> 若不想用 Pages，也可以放到任意静态托管（Vercel / Netlify / Cloudflare Pages），把同一份 `privacy.html` 传上去即可。
