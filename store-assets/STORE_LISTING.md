## 2. 商品详情（详细描述）

```
Capx 是一个专注「干净」的浏览器扩展，提供两个彼此独立的功能：截图 与 永久隐藏。所有处理都在本地完成，不上传任何数据。

【功能一 · 截图：先消除，再截取，截完自动复原】
· 消除：悬停就近高亮，滚轮把范围提升到整块容器，点击后元素以 display:none 真实退出布局，下方内容自动上移。
· 截取：三种模式随时切换——消除 / 选元素 / 圈选，可截整个元素或任意矩形区域。
· 无痕：导出后页面 100% 自动复原，连 style 属性都恢复到原样。
· 截后编辑：箭头 / 矩形 / 文字 / 画笔 / 马赛克 / 裁切，导出保持原始分辨率。
· 导出：PNG / JPG，保存 + 复制剪贴板，历史缩略图可一键定位文件。
· 快捷键：Alt+Shift+X 启动，1/2/3 切模式，Ctrl+Z 撤销，Esc 退出。

【功能二 · 隐藏元素：标记一次，以后打开就自动隐藏】
· 按站授权：只在您点「启用本站」并同意后获得该站点权限；安装时不申请任何网站权限。
· 点击即隐藏：连续点多个元素，点到就立刻从页面消失；顶部实时计数。
· 错了可撤：Ctrl+Z 撤销最后一项，「明细」里可逐项恢复，「退出」不保存则全部还原。
· 一次保存：选完点「保存」，一次性存为永久规则；刷新、下次打开都自动隐藏。
· 透明可见：每条规则都显示当前页面的真实匹配状态；网站改版导致选择器失效时一眼看出，重新拾取即可。
· 支持 open Shadow DOM；规则按域名分组，可临时禁用、删除、清空，只看您管理的站点。

【隐私与权限】
· 纯本地：规则、设置、截图历史只存本机，不联网、不上传。
· 截图功能只需 activeTab：点击图标才注入当前页面。
· 隐藏功能用可选主机权限：同意哪个站点，就只在该站点自动注入；随时可撤销。
· 安装时不会获得任何网站访问权。

【适用】
论坛 / 社区 / 新闻 / 文档页里，想截一张没有广告、价格、隐私信息的干净图；或想让某个站点上烦人的推荐、横幅、提示以后都不再出现。
```

## 3. 权限说明（逐项填开发者后台的 justification）

| 权限 | 用途说明（可原样粘贴） |
|---|---|
| `activeTab` | 仅在用户点击扩展图标时，对当前活动标签页注入截图脚本，无需事先获得所有网站的访问权限。 |
| `scripting` | 用于向当前标签页注入截图/隐藏的 content script 及其 CSS，实现页面内的消除、选取、拾取与自动隐藏。 |
| `storage` | 保存用户设置、最近截图缩略图、按站点分组的隐藏规则；全部仅存本机，不上传。 |
| `downloads` | 把截图保存到用户的下载目录（可自定义子文件夹），并在历史记录里提供「在文件夹中显示」。 |
| `clipboardWrite` | 将截图复制到系统剪贴板，方便粘贴到聊天/文档。 |
| `optional_host_permissions: <all_urls>` | 隐藏元素功能需要。仅当用户主动点击「启用本站自动隐藏」并在浏览器弹窗中同意后，才获得该具体站点的访问权限，用于每次页面加载时自动注入隐藏脚本。安装时不会授予；用户可随时在扩展设置中撤销。这不是「读取所有网站数据」——只是授权池的声明方式，实际权限按站点逐个请求。 |
